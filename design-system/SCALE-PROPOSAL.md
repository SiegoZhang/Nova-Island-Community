## 五、间距

### 建议的标准阶梯

`0 / 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64`，对应现有 `--space-*`。

命名例外，必须用专用 Token，不能直接写数值：

- `--shell-gap: 6px`：外壳和主卡之间的间隔
- `--capsule-inset: 3px`：筛选胶囊的内边距
- `--hairline-offset: 2px`：焦点轮廓偏移、徽章微调

就近取档。两边距离相等时：**组件内部**（内边距、图标与文字之间）取较小值，**组件之间和区块之间**取较大值。

## 六、断点

### 建议的标准断点

| 名称 | 条件 | 发生什么 | 合并的现有值 |
| --- | --- | --- | --- |
| compact | ≤ 600px | 手机竖屏：卡片单列，筛选条重排 | 380、400、480、520、540、600、650 |
| mobile | ≤ 760px | 侧栏变成抽屉，标题降级，页面边距收窄 | 760、800、850 |
| medium | ≤ 1100px | 双栏变单栏，辅助栏移走，阅读目录收起 | 900、980、1000、1100、1150、1200 |
| wide | ≥ 1440px | 内容网格加一列 | 1440、1500、1600、1800 |

- 和输入方式有关的查询（`pointer:coarse`、`hover:hover`、`prefers-reduced-motion`）不属于宽度断点，保留。
- `min-width` 写法统一为上一档加 1，例如 `min-width:761px`。
- 组件内部的尺寸响应优先用容器查询（原型已在插画中使用 `cqw`），不新增视口断点。
- **风险**：1150 / 1200 合并到 1100 后，首页 portal 和课程区在 1100–1200px 之间的布局会变化，需要逐页目检。

## 八、确认后的迁移顺序

1. 在 `html-pages/prototype/assets/tokens.css` 中加入新阶梯：新增的字号角色、圆角档、阴影、玻璃、插画和图表分组。旧 Token 暂时保留为别名。
2. 逐个 CSS 文件迁移，从影响最小的开始：`site-tour` → `guide-progress` → `feed-filters` → `forum` → `ranking` → `home`。每个文件迁完后在 1440 / 1100 / 760 / 390px 下截图对比。
3. 重新运行 `audit-scale.py`，目标是除豁免项外，字号、圆角、间距的写死值降到 0。
4. 运行 `sync-tokens.py`，并更新 SYSTEM.md 和 foundations.html 中的数值。
5. 删除过渡别名。

建议迁移时为每个现有声明生成一张逐条清单（文件、选择器、现值 → 新值），标出需要目检的地方。确认本提案后再生成。
