间距

4px 为单位，11 档。近的是一组，远的是另一件事。

  • 阶梯
  • 在卡片里
  • 在页面里
  • 例外
  • 给 AI 用

阶梯

4--space-1
图标与文字的微调、徽章之间
8--space-2
图标与文字、元信息各项
12--space-3
标题到摘要、手机网格
16--space-4
工具栏到内容、手机留白
20--space-5
内容卡内边距、卡片网格
24--space-6
面板卡内边距、区块标题到内容
32--space-8
区块之间、页面左右留白
40--space-10
页面底部留白
48--space-12
宽屏顶部留白
64--space-16
空状态上下留白

0 也是一档。负边距只能取阶梯上的值。

给 AI 用

一个模块覆盖间距、圆角、控件高度和布局。

Prompt · 贴给任何 AI
请按 Nova Island 的尺寸规范排布（间距、圆角、控件高度、布局）。

间距只用这 11 档（4px 为单位）：0、4、8、12、16、20、24、32、40、48、64。
例外只有三个：6px 外壳间隔、3px 胶囊组内边距、1px 边框。负边距只能取上面的档位。

元素之间用多少间距：
| 位置 | 间距 |
| --- | --- |
| 图标与文字、头像与名字、标签之间 | 8 |
| 徽章的内边距 | 2 × 8（上下 2 只用于徽章） |
| 元信息一行里的各项 | 8 |
| 卡片标题到摘要 | 12 |
| 摘要到卡片底部的元信息 | 20 |
| 内容卡片的内边距 | 20 |
| 面板卡片（侧栏卡、作者卡、榜单卡）的内边距 | 24 |
| 横幅卡片的内边距 | 24 × 32 |
| 列表行（帖子行）的内边距 | 24 × 20 |
| 卡片网格的间距 | 20（手机 12） |
| 同一栏里上下叠放的卡片之间 | 24 |
| 卡片里的小标题到内容 | 16 |
| 卡片里的设置行、成员行 | 上下 16、左右 0，行之间用分隔线 |
| 统计数字：标签到数字 / 各项之间 | 4 / 16 |
| 主栏与侧栏之间 | 24 |
| 筛选工具栏到内容 | 16 |
| 区块标题到内容 | 24 |
| 区块之间 | 32（手机 24） |
| 页面标题区到内容 | 32 |
| 页内标签页到内容 | 24 |
| 空状态的上下留白 | 64 |
| 主内容区左右留白 | 32；≤1100px 24；≤760px 16 |

圆角按元素的角色选，只用这 7 个值：
| 圆角 | 用在哪里 |
| --- | --- |
| 0 | 列表行、表格、分隔区（行放在卡片里，由卡片负责圆角） |
| xs 4 | 徽章、内容类型标签、复选框、进度条 |
| sm 8 | 方形图标按钮、复制按钮这类小型方按钮 |
| sm 8 | 单行输入框 |
| md 12 | 多行输入框、学习小节行、嵌套在卡片里的面板、图片 |
| lg 20 | 胶囊组容器（筛选组）、弹层、菜单 |
| card 24 | 所有卡片、主外壳、侧栏导航项、可点击的整行（悬停出现底色的行） |
| full 999 | 按钮、筛选胶囊、搜索框、返回按钮；头像和圆点用 50% |
嵌套规则只用于“外框紧紧包着一个子元素”的情况：内层圆角 = 外层圆角 − 两者之间的内边距。例如 20 的胶囊组加 3 的内边距，里面的胶囊用 full。卡片里的普通内容（输入框、面板、图片）不套公式，按上表的角色选。

控件高度：
| 控件 | 高度 |
| --- | --- |
| 筛选胶囊 | 32（胶囊组外框 38 = 32 + 3 × 2） |
| 按钮、输入框、搜索框 | 40 |
| 点赞、评论、收藏等互动按钮 | 36（圆角 full，内边距 8 × 12） |
| 区块里最重要的那个按钮（横幅、空状态） | 48 |
| 只有图标的按钮、头像按钮、返回按钮 | 44 × 44（触控目标） |
| 侧栏导航项、学习小节行 | 44 / 48 |
按钮左右内边距 16（大按钮 20），胶囊左右内边距 12。

表单：
| 位置 | 值 |
| --- | --- |
| 标签到输入框、输入框到错误提示或说明 | 8 |
| 字段之间 | 20 |
| 单行输入框 | 高 40，内边距 8 × 12，圆角 8 |
| 多行输入框 | 最小高 96，内边距 12 × 16，圆角 12 |
| 表单最后一个字段到按钮组 | 24 |
| 按钮之间 | 12 |
| 开关 | 产品里没有开关。设置项用复选框（16 × 16，圆角 4，与文字间距 8）；一定要开关时先告诉用户 |

页内标签页（设置、通知、收藏等页面里切换分区）：横排文字标签，左右间距 24，每个标签内边距 12 × 4，当前项下方 2px 黑色下划线，整行下方 1px 分隔线。不要在全局左侧导航之外再加一列竖向导航。

头像：卡片元信息 22，顶栏 32，列表行 36，账号资料区 44，文章作者 48。头像到旁边的名字：行内 8，资料区 12。

布局：
- 桌面：左侧导航 224 宽；内容区是一张大卡片，四周与窗口、导航保持 6 的外壳间隔。
- 卡片网格：≥1101px 3 列，≤1100px 2 列，≤600px 1 列。
- 主栏 + 侧栏：2 : 1，间距 24；≤1100px 上下排列。页面只有一个 .nv-split，放在 .nv-main 里面。
- 断点只用 600 / 760 / 1100 / 1440：
  - ≤600：手机，网格单列，横幅内边距收到 24。
  - ≤760：侧栏变成从左侧滑出的抽屉，顶栏只留图标，左右留白 16。
  - ≤1100：双栏变单栏，网格变 2 列，左右留白 24。
  - ≥1440：宽屏，主内容区顶部留白 48。

如果可以引入 CSS，直接使用 size.css：变量 --space-*、--radius-*、--control-*、--avatar-*（xs 22 / sm 32 / md 36 / lg 44 / xl 48）、--field-gap；布局类 .nv-main、.nv-card-grid、.nv-split、.nv-section、.nv-section-head。
