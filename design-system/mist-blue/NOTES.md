# 新岛设计体系 · 雾蓝独立版

本版独立存放于 `design-system/mist-blue/`，原版文件保持不变。预览：http://127.0.0.1:4187/mist-blue/ 。

用户提供的四种色值：暖白 `#F9F7F7`、雾蓝灰 `#DBE2EF`、湖蓝 `#3F72AF`、藏青 `#112D4E`。其余深浅表面为派生色。圆角、中文排版与组件交互沿用原版。

浅色主要按钮使用湖蓝配纯白文字，深色主要按钮使用雾蓝灰配藏青文字。

独立引入本目录的 `tokens.css` 与 `components.css` 即可使用。`tokens.json` 导出本版本的色彩、间距与圆角；技术变量名保持兼容。
