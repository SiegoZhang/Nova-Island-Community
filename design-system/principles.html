GUIDELINES / RULES

设计规则

任何新设计都必须满足的 20 条规则。每条都能检查：标“脚本”的由 check-design.py 自动发现，标“人工”的需要在页面上核对。规则背后的理由见决策记录。

python3 design-system/scripts/check-design.py          # 只报告新增的违规
python3 design-system/scripts/check-design.py --all    # 包含已知的历史违规

数值与 Token

#规则反例检查依据
R1颜色只用语义 Token；组件文件里不写十六进制或 rgb 色值新卡片写 color:#626262，而不是 var(--text-secondary)脚本D23
R2字号只用 --type-* 的 10 档；界面文字不小于 11px榜单注释写 10px脚本D05
R3页面 H1 用 --type-page，手机用 --type-title-lg；不另设页面标题字号新的活动页 H1 写 28px人工D06
R4圆角按角色取值：小元素 xs、按钮与输入框 sm、嵌套面板 md、浮层 lg、主卡 card、胶囊 full卡片里的图片用 24px，与外层卡片一样圆脚本D08
R5间距只用 --space-*；例外只有 --shell-gap 6、胶囊内边距 3、2px 微调标题下方写 margin-bottom:28px脚本D09
R6媒体查询只用 600 / 760 / 1100 / 1440px；组件内部的尺寸变化用容器查询为新卡片加 @media (max-width:900px)脚本D10
R7插画和数据图的颜色只从 --illus-*、--chart-* 取；同一个工具在所有图表里颜色相同树图里 Claude 用绿色，分布条里用橙色人工D17

颜色与材质

#规则反例检查依据
R8同一区块最多一个黑色主按钮（ds-button primary）；列表项和卡片里的操作用 secondary 或 ghost活动列表每张卡片都放黑色“报名”按钮人工D11
R9蓝色只表示当前位置、选中、链接、进度；“完成”“成功”一律用 --status-success-*已完成的课时用蓝底标记人工D11、D12
R10可读文字只用 --text-heading、--text-primary、--text-secondary；--text-disabled 只用于禁用和占位用 #949494 写日期和阅读数脚本（色值）D13
R11普通卡片不加阴影，悬停换相邻色阶；只有浮在内容上的元素用 --shadow-sm/md/lg内容卡悬停时整卡变暗，或常驻投影脚本（写死阴影）D14
R12玻璃只用 --glass-fill 两档，只用在浮动控件、弹层、滚动边缘；标签、话题等中性底色只用 --fill-*在整段正文后面铺玻璃；标签底色写 rgba(0,0,0,.05)脚本（色值）D15

内容与状态

#规则反例检查依据
R13内容卡不强制等高，标题完整换行；没有配图用纯文字色卡；不生成装饰封面；第三方标志不染色为了网格整齐把标题截成一行人工D18、D19
R14每个加载数据的区域都要有四种状态：结构对应的骨架、两种空状态（筛选无结果 / 板块无内容，文案不同）、原位错误（“加载失败，请重试” + “重新加载”）、列表到底所有异常都显示同一句“暂无数据”人工D21
R15筛选和路由状态写进 hash；详情页返回来源，不统一回首页筛选只存在内存里，刷新即丢失人工D22
R16主导航点击后立即选中；加载失败时保持选中等内容加载完才切换高亮人工D21

可访问与实现

#规则反例检查依据
R17状态不能只靠颜色表达：赞、藏、选中要有 aria-pressed、aria-current 或文字点赞只把图标变红人工SYSTEM.md
R18可交互元素有可见的键盘焦点（--focus-ring）；去掉 outline 必须提供替代样式；触控命中区域至少 44px搜索框 outline:none 且没有替代（现存问题）脚本（outline）SYSTEM.md
R19不新增 !important；只有减少动效和隐藏元素可以使用为了压过页面样式给按钮颜色加 !important脚本D24
R20新的设计决定写进 DISCUSSION.md 的“待确认”，确认后补进决策记录；不在代码里悄悄引入新值新增一种灰色却没有记录人工待定

插画内的文字、字形图标、头像首字母和随容器缩放的 clamp() 不受 R2、R4、R5 约束；脚本已按选择器排除这些情况。
