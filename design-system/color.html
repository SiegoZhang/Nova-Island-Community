颜色

颜色帮助用户分清哪里可以操作、自己在哪里、事情进展如何。这一页说明 AI Community 的颜色由什么构成，以及怎样通过 Token 使用它们。

颜色构成

AI Community 的颜色分成三类：饱和色负责强调和状态，中性色负责文字、表面和边框，透明色负责玻璃和轻微的底色变化。设计时不直接使用这些原始值，而是通过下一节的语义 Token 引用它们。

饱和色

文件夹蓝是唯一的品牌色，从 50 到 700 共八档。浅的几档做底色和边框，500 是交互强调色，600 是链接和强调文字。

中性色

中性色从纯白到纯黑共九档。界面里大部分颜色都是中性色：白色阅读表面放在 50 的画布上，文字只用 600、800、900 三档，400 只给禁用和占位。

深色模式有一组独立的中性取值，见调色板。

透明色

透明色只有两类。玻璃是半透明的白色表面，配合背景模糊，用在浮动控件、弹层和滚动边缘；中性填充是在白色上叠加一点黑色，用在标签和话题的底色。

用 Token 应用颜色

组件只使用语义 Token。语义 Token 的名字说明这个颜色“用来做什么”，而不是“它是什么颜色”。这样同一个名字在浅色和深色模式下可以取不同的值，组件不用改。

--status-success-text
类别角色用途

名字从左到右依次是：类别（这是哪一类颜色）、角色（表达什么）、用途（用在文字、底色还是边框上）。不是每个 Token 都有三段，比如 --accent 只有类别。

类别用来做什么例子
--action-*主要操作按钮--action-primary、--text-on-action
--accent-*当前位置、选中、链接、进度、焦点--accent、--accent-text、--accent-surface
--surface-*页面和卡片的底色--surface-canvas、--surface-default
--text-*文字--text-heading、--text-secondary
--border-*边框和分隔线--border-default、--border-subtle
--status-*成功、危险、信息--status-success-text
--badge-*内容分类，见分类色--badge-purple-bg
--reaction-*点赞和收藏--reaction-liked
--illus-*、--chart-*插画和数据图，见数据可视化--chart-codex

颜色角色

每种颜色只承担一个角色。看到黑色，用户知道这里可以操作；看到蓝色，知道这是当前位置或可点的链接；看到绿色，知道事情已经完成。角色一旦混用，这些判断就失效了。

角色什么时候用Token
主要操作请用户去做一件事，一个区块最多一个--action-primary · --text-on-action
强调当前位置、选中、链接、进度、焦点--accent-*
表面画布、卡片、次级区块、悬停--surface-*
文字标题、正文、次要信息、禁用--text-*
边框控件描边、卡片边界、分隔线--border-*
成功完成、已报名、接入成功、增长--status-success-*
危险失败、删除、无法完成--status-danger-*
信息中性的说明和提示--status-info-*
分类内容类型和标签，可以互换--badge-*
阅读互动点赞、收藏，只在阅读互动中使用--reaction-*

深色底上用反色 Token

在黑色主按钮、蓝色强调色这类深色底上，文字和图标要用对应的反色 Token，而不是写死白色。深色模式下这些底色会变浅，反色 Token 会跟着变深。

继续学习文字 --text-on-action已选中文字 --text-on-accent

交互状态

交互状态用相邻的颜色表示，不用黑色遮罩。按钮悬停时变成相邻的一档；卡片悬停时，底色换成同色系更深一点的颜色，比如蓝色纯文字卡从 --article-surface-blue 变成 --article-surface-blue-hover。

元素默认悬停
主按钮--action-primary--action-primary-hover
蓝色纯文字卡--article-surface-blue--article-surface-blue-hover
中性卡片--surface-default--feed-surface-neutral-hover
标签--fill-subtle--fill-hover

选中和焦点要能区分

选中表示“这是当前的那一个”，用浅蓝底色加蓝色文字；焦点表示“键盘现在停在这里”，用一圈 2px 的蓝色轮廓。两者可以同时出现：已选中的筛选项被键盘聚焦时，浅蓝底色和蓝色轮廓都要显示。

选中焦点选中 + 焦点

悬停和按下叠加在当前状态上

悬停和按下是在当前状态的基础上再变一点，而不是换回默认状态的悬停色。已选中的元素被悬停时，仍然保持选中的浅蓝底色，只在此基础上略加深，不能变回中性的灰色悬停底。现有组件是否都遵守这一点，尚待逐个核对。

图标的悬停与按下

图标使用 currentColor，颜色跟随所在的按钮或链接。图标按钮悬停时改变的是按钮的底色（--surface-secondary），图标本身的颜色不变；只有表示“当前”的图标，例如当前页面的导航图标，才使用蓝色。

颜色的可访问性

文字与背景的对比度至少 4.5:1，大号文字、图标、焦点轮廓等非文字元素至少 3:1。另外，状态不能只靠颜色表达：点赞、收藏、选中都要同时有 aria-pressed、aria-current 或文字说明，色弱用户才能分辨。

深色模式

深色模式通过给 .nova-ds 加上 data-theme="dark" 开启。所有语义 Token 在深色下都有对应的值：表面变成 #191919 到 #333333 的深灰，文字变成浅灰，强调色从蓝 500 换成更亮的蓝 300，选中底色改为在深色表面上混入少量蓝色。只要组件只用语义 Token，切换主题时不需要改任何代码。

目前深色模式的 Token 已经齐全，但还没有逐页验收；玻璃、插画和图表在深色下的表现也还没有检查。新组件不要写死任何颜色，否则在深色模式下会出错。完整的深浅对照见调色板。
