# 新岛产品原型

独立入口：index.html。课程、文章和 assets 均从设计系统复制到本目录后独立维护，不引用设计系统页面或资源。

- index.html：首页与 sidebar，个人中心和入门指南。
- course.html、article.html：原型内独立维护的课程和文章详情，使用与首页一致的产品导航及个人菜单。
- assets/：原型自己的样式、交互脚本和设计变量副本。
- 论坛暂显示空状态；旧 UX 对照原型副本已删除。

设计系统唯一入口为 ../../design-system/index.html，规范、组件组合及课程和文章示例均在 design-system/ 维护。上一级 index.html、course.html、article.html 仅保留兼容跳转。原型使用本目录独立资源，设计系统更新不会自动同步到原型。

上一级 home.html 保留为旧预览地址的兼容副本，其 base 指向本目录；不跳转设计系统。


## 内容频道首页

首页改为常驻搜索、推荐与七个主题频道、封面内容网格和频道精选。课程继续是左侧一级入口，入门指南仍在 sidebar 底部，收起后从个人中心找回。

`assets/catalog.js` 统一维护九条现有示例内容、频道归属和 HTML/CSS 封面。课程页、文章页、搜索和频道页使用同一目录。商业变现尚无样例，频道内显示可恢复的空状态，首页不添加占位推荐。外部教程与部分文章仅展示摘要，明确提示完整正文尚未接入。

频道与搜索条件保存在 URL hash，支持刷新及浏览器前后退；阅读节选后可返回原列表。所有页面与资源仍位于原型目录。`../home.html` 仅为旧预览入口的兼容副本。

本轮验证：两份脚本通过语法检查；七频道切换、商业变现空状态、关键词搜索与零结果、阅读返回原频道/搜索结果、课程与文章本地详情跳转通过浏览器检查。已查看 1280px 桌面和 390px 手机布局，验证手机侧栏指南和横向频道切换；所有 HTML 本地链接与资源仍在原型目录内。

推荐页现为门户式营销布局：主视觉与编辑选读、重点课程、实践文章及论坛邀请。七个主题频道继续使用原来的内容列表。所有宣传文案为设计提案，未添加虚构会员数量、学习成果或报名信息。

详情页通过 assets/detail-shell.js 和 detail-shell.css 接入原型侧栏与个人菜单；侧栏课程、文章返回对应内容列表。返回按钮保留来源频道或搜索参数。所有 HTML 链接与资源已检查，均在 prototype 内。

搜索与头像位于 main 卡片外的独立顶行，使用 assets/workspace-header.css 和 workspace-header.js。左侧导航位置保持不变，个人菜单从右上角头像展开。首页、课程与文章详情统一此布局。

入门指南卡片靠近侧栏底部，底部保留 32px 留白；与导航至少保持 32px 间距。

## 岛民论坛

论坛位于 index.html#community，由 assets/forum.js 和 forum.css 提供列表、标签筛选、关键词搜索、我的帖子、详情与发布编辑页。五条示例为线上论坛的整理摘要，保留作者与原帖链接。新帖和一份当前草稿存储于浏览器 localStorage，不调用线上发布接口。

发布支持 200 字标题、50000 字正文、多选标签、基础 Markdown 排版和预览。输入自动保存草稿，个人菜单的“我的草稿”可继续编辑；发布后跳转详情并清空草稿。图片、附件与真实账号服务尚未接入。浏览器已验证草稿刷新恢复、正文预览、发布详情与刷新保留。

## 原站图片替换（2026-09-20）

已在登录的 Chrome 中查看精华第 2 页，核对个人网站教程、冥想、Fable 的真实配图。内容封面统一读取 image / sourceImage，恢复频道目录已有的 26 条原图引用，新增个人网站教程原图，WorkBuddy 使用已保存的原始配图。没有来源图片的示例不再生成 HTML/CSS 封面；首页不再强制覆盖为 AI 生成课程图。界面导览和功能图标不属于帖子配图。

限制：原站媒体匿名下载返回 HTTP 401，新增图片目前仍引用原站地址，可能依赖浏览器登录状态；未宣称已离线保存。浏览器安全策略阻止打开本地 file 页面，本轮仅完成脚本语法与渲染函数检查，尚未确认本地页面的远程图片加载。

### 图片加载修复（2026-09-20）

原站媒体受登录权限保护，直接外链会在本地页面失效。现已通过登录浏览器下载全部 27 张封面，保存于 assets/original-media，并为目录配置本地 image 路径；sourceImage 仅保留为来源记录，来源清单见 assets/original-media/sources.json。27 张文件已通过图像解码与本地渲染路径检查，不再需要原站登录或网络。此前“仅保留远程链接”的限制已解除；本地页面的浏览器视觉复核仍受 file URL 策略限制。

## 导航分组与专栏（2026-09-21）

首页作为独立入口；知识学习包含课程、专栏、资讯；社区参与包含论坛、活动、实战、榜单。首页、独立详情和旧 home.html 兼容入口同步分组。侧栏支持纵向滚动，窄屏仍使用抽屉导航。

新增 `#columns` 专栏页，按目录中现有七个主题展示文章合集，数量由实际内容计算；`#columns?id=主题` 展示对应内容。复用现有原型内容，没有新增虚构正文。阅读和独立文章页可返回来源专栏，并保留专栏选中状态。

验证：修改脚本通过 Node 语法检查；浏览器验证专栏列表、主题内容、阅读返回、独立文章返回、桌面和 390px 手机导航布局，未发现控制台错误。

专栏按最新要求改为统一空状态，沿用活动、实战页面的卡片插画，展示“暂无专栏”与“浏览资讯”入口；不再展示七个主题合集，旧专栏主题链接也统一显示空状态。

## 资讯发布权限

`assets/articles.js` 的 `articleAccount` 是本地账号角色样例，默认普通成员（member）。只有 admin 显示发布入口并允许编辑、草稿保存和发布；直接访问 compose 参数也校验角色。原型角色不读取 URL 或浏览器存储。此限制仅用于演示，接入真实账号时必须以服务端认证会话替换角色样例，并在每个写入接口检查管理员权限。论坛发帖维持现有行为。


## 文件夹蓝色阶（2026-09-22）

产品原型的蓝色统一在 `assets/tokens.css` 维护：50 #F2F5FF、100 #E0E8FF、200 #BDCDFF、300 #8FABFF、400 #5C84FF、500 #0140FF、600 #0033CC、700 #082A99。

组件引用语义变量：浅背景 `accent-surface-soft`，选中和标签背景 `accent-surface`，边框及轨道 `accent-border`，文字 `accent-text`，交互强调 `accent-active`，图表 `chart-codex`，文件夹插画 `illustration-blue` / `illustration-blue-depth`。深色模式通过语义变量映射，不改变基础色阶。主按钮保持黑色；成功状态独立使用绿色。

首页文件夹保持 500 / 700 主色；入门指南当前周使用浅蓝底与灰黑正文；Token 榜的图表和数字分别使用图表色与文字色。原始内容图片及品牌标志保持原样。设计系统和历史导出不随产品原型自动同步。
